# Bank Marketing Data Cleaning - DataCamp Project 1

## Description

A data cleaning and transformation project completed as part of DataCamp's Data Engineering coursework.

## Skills Demonstrated
- Python
- Pandas
- NumPy
- Data cleaning and transformation
- Datetime manipulation
- Boolean conversion
- DataFrame filtering and selection
- CSV data processing
- Exporting cleaned datasets

## Project Work
- Cleaned and standardized categorical values
- Converted contact dates into a usable date format
- Converted categorical yes/no outcomes into boolean values
- Split the dataset into client, campaign, and economic datasets
- Exported cleaned datasets as separate CSV files
